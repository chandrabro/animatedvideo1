# Puppet Stage

Browser-based animated story maker. The whole app is one file: `index.html`.

## Deploy (no installs)
1. GitHub: create a repository, then Add file > Upload files, and add `index.html` (and this README).
2. Vercel: Add New > Project > import the repository > Deploy. No settings needed.

## Use
Characters panel (left) > make avatars. Scene panel (right) > background, camera, add up to 3 characters,
set movement, action, facing, expression, and upload or record a voice. Bottom strip > manage scenes.
Export MP4 needs desktop Chrome or Edge.
